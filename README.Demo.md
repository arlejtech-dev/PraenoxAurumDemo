# Praenox Aurum Demo

Praenox Aurum Demo is the free, time-limited edition of Praenox Aurum, Arlej Tech's Android
biometric sound-synthesis app. It is a separate, side-installable APK
(`com.arlejtech.praenox.demo`) that runs the same engine as paid Aurum for **7 days**, so you can
try the real app before buying it.

## How it works

1. Enter daily HRV, resting heart rate, deep sleep, REM sleep, stress, and sleep duration.
2. Praenox calculates and saves the day's recovery state.
3. Select a sound palette and generate a biometric soundscape.
4. Listen in the built-in player and continue adding real daily data.
5. Pattern Drift, Learning, Milestones, Context, and Fusion develop from the saved history.

## Main features

Everything in paid Aurum is available in the Demo, for the full 7 days:

- Personalized biometric soundscape generation
- Long-duration playback
- Pattern Drift charts and saved-day comparisons
- Sleep Planner and sleep-debt tracking
- Optional lifestyle and sleep-context check-ins
- Learning reports, milestones, and progression
- Fusion recovery outlook with measured prediction performance
- Multiple local user profiles

## What's different from paid Aurum

- **7-day trial, device-bound.** The Demo licence key is tied to your exact phone and expires
  automatically seven days after it's issued. There is no way to extend or reset the countdown
  on the same key or device.
- **Data Vault import/export is disabled.** You cannot import or export a full profile ZIP,
  write automatic Data Vault backups, or choose an external vault folder.
- **WAV export is disabled.** Soundscapes can be listened to in-app but not exported as audio
  files.
- **Two countdown reminders.** You'll get a notification 48 hours before expiry ("Your Aurum
  Demo ends in 2 days") and another 24 hours before ("Your Aurum Demo ends tomorrow"), so the
  trial ending is never a surprise.
- **Expiry screen.** Once the 7 days are up, the Demo opens directly to a simple screen with two
  options: buy Praenox Aurum, or close the app. No data-entry or playback screens are reachable
  from there.

Paid Aurum and the Demo install side by side as separate apps and never share private data, so
trying the Demo never touches an existing paid Aurum installation.

## Activation

1. Install the Demo APK and open it.
2. Copy the device request code shown on the activation screen.
3. Send that code in to request a free Demo key.
4. Paste the returned key on the activation screen and tap **Activate 7-day Demo**.

The key only works on the device that generated the request code, and only for the Demo edition —
paid Aurum licences do not activate the Demo, and Demo keys do not activate paid Aurum.

## Privacy

Praenox Aurum Demo is local-first, the same as paid Aurum: health readings, profiles, context,
soundscapes, and learning history stay on the device. Because import/export is disabled in the
Demo, there is no way to carry that 7 days of data into paid Aurum or another device — keep that
in mind if you want to preserve anything you enter during the trial.

## Requirements

- Android 8.0 or newer (API 26+)
- Portrait orientation
- ARM64 Android phone

Praenox Aurum is a personal wellness and sound-synthesis tool. It is not a medical device and does
not diagnose, treat, or replace professional medical care.
